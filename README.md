## Project Methodology

I have not written a single line of c or configuration for this project. It is completely agent driven. This effort started at the beginning of the year, but I started seriously pursuing it a few months ago.

A lot of models have contributed to the project. The commit log contains some of them. 

Essentially, the harness works like this:

1. Identification and bootstrapping
  - Run a ton of heuristics to be reasonably confident of the toolchain for the underlying exe
2. Split code into exe and overlays
3. Find matching c one by one until there's nothing left to find
